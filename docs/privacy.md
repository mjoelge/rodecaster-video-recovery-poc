# Privacy and data handling

This repository contains source code and generalized method notes only. It
must not contain recovered media, disk images, PhotoRec output, previews,
waveforms, transcripts, real filenames, paths, serial numbers, timestamps,
hashes, disk offsets, catalogs, manifests, logs, or screenshots from a case.

The allowlist `.gitignore` admits only documentation, Python source and
synthetic tests, and the CI workflow.
It is a guardrail, not a substitute for reviewing the staged diff before every
push. Runtime paths and generated outputs belong outside the checkout. Do not
paste real command output into issues or pull requests.

If adapting this code for another investigation, keep the raw source read
only, write to a different physical disk, and preserve originals. A published
example should be synthetic or created from material whose owner explicitly
authorized publication.
